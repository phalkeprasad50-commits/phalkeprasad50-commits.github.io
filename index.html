AssessPrep

A timed mock-assessment backend. The server owns the clock: expiry is stored when the test starts and late submissions are marked TIMED_OUT. It ships through a GitHub Actions pipeline that tests, builds a Docker image, scans it with Trivy and publishes it.

Java · Spring Boot · PostgreSQL · Docker · GitHub Actions

View on GitHub

SplitEasy

A group expense splitter with equal, exact and percentage splits. A greedy algorithm settles debts in at most n−1 payments, and database transactions keep the data consistent.

Angular · Node.js · PostgreSQL · JWT
